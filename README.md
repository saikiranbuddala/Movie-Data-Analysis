# Movie-Data-Analysis
# 🎬 Movie Data Analysis Using Python

## Project Overview
Analyzed a dataset of 1000 movies to uncover insights about 
ratings, genres, budgets, and success factors using Python.

## Domain
Python Development

## Internship

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset Details
| Column | Description |
|--------|-------------|
| title | Movie title |
| vote_average | Rating (3.0 - 9.5) |
| budget | Production budget ($) |
| revenue | Box office revenue ($) |
| popularity | Popularity score |
| genres | Movie genre |
| director | Director name |
| runtime | Duration (minutes) |
| release_year | Year of release |
| vote_count | Number of votes |

## Research Questions Answered
1. Which genres are most popular?
2. How are ratings distributed?
3. Does budget affect revenue?
4. Do higher budgets get higher ratings?
5. Which genre has the highest ratings?
6. Which director has the highest average rating?
7. Does popularity affect revenue?
8. Which year had the most releases?

## Visualizations Created
1. Rating Distribution
2. Top Genres by Count
3. Budget vs Revenue
4. Budget vs Rating
5. Genre vs Average Rating
6. Correlation Heatmap
7. Top Directors by Movie Count
8. Movies Released Per Year
9. Popularity vs Revenue
10. Runtime Distribution

## Key Findings
- Most popular genre guides production decisions
- Average rating of movies is around 6.3 out of 10
- Higher budget generally leads to higher revenue
- Budget does NOT guarantee good ratings
- Average runtime is around 130 minutes
